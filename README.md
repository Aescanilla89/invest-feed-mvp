# TradeFinder

Research de mercado para inversores que quieren entender por qué una oportunidad aparece en el radar.

## Demo

- [Abrir TradeFinder](https://frontend-inky-nine-48.vercel.app/)
- [Ver planes Pro](https://frontend-inky-nine-48.vercel.app/pricing)

## Qué hace

TradeFinder combina:

- Stage Analysis de Weinstein;
- criterios CAN SLIM;
- catalizadores recientes procedentes de fuentes públicas;
- explicaciones en lenguaje claro;
- cartera modelo e histórico de señales.

El producto está pensado como una herramienta de investigación educativa. No ejecuta órdenes ni ofrece recomendaciones personalizadas.

## Acceso fundador

El acceso fundador cuesta **149 € al año** e incluye el feed completo, criterios explicados, catalizadores e histórico de cartera modelo. Para solicitar una plaza, usa la página de [planes Pro](https://frontend-inky-nine-48.vercel.app/pricing).

## Stack

- Frontend: Next.js
- Backend: FastAPI
- Base de datos: PostgreSQL
- Datos: Alpaca IEX y SEC EDGAR
- Automatización: GitHub Actions

## Aviso

La información se ofrece con fines educativos y de investigación. Las puntuaciones no son predicciones ni recomendaciones de compra, venta o mantenimiento. Cada usuario debe hacer su propio análisis y asumir sus decisiones.
